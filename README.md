# Mantix Tech — GitHub Pages

## Publicar
1. Crea un repositorio público en GitHub.
2. Sube `index.html` y `.nojekyll` a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Pulsa **Save** y espera a que GitHub Pages publique el sitio.

El archivo `index.html` corresponde a la versión P01–P18 perfil v12.
